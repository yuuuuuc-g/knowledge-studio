# ADR 0001: Start With A Docs-First Product Shape

## Status

Accepted

## Context

The product idea spans reading, knowledge graphs, writing, language learning, AI generation, publishing and social motivation. Jumping directly into a full application stack would risk hiding the central product question: can the system move a student from reading to question formation to writing?

## Decision

Start with a docs-first project that defines the domain language, MVP loop, user flows and module boundaries. Use these documents as the base for future prototypes and GitNexus indexing.

## Consequences

- The project is immediately understandable to both humans and AI agents.
- Future implementation can choose the right stack after validating the core loop.
- The first prototype should focus on one vertical slice rather than a complete platform.

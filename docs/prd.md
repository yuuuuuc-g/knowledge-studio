# Initial PRD

## Objective

构建一个面向大学生的知识管理与创作系统，帮助用户完成从经典阅读、结构化思考、外语语料积累到写作发布的闭环。

## Target Users

- 中国大学生，尤其是希望弥补阅读、写作和外语能力短板的人。
- 自学者和通识教育爱好者。
- 希望把读书笔记转化为文章、绘本、音频或分享作品的学生。

## Needs

1. 读经典书籍不足。
2. 缺乏完整知识结构。
3. 外语能力欠缺，语料库不足。
4. 写作积淀不足，缺少持续输出。

## MVP Scope

### Reader And Canvas

- 左侧阅读文本，右侧结构图 Canvas。
- 支持手动创建节点、连线和简短注释。
- 支持 AI 基于当前章节预生成结构图。
- 支持从文本段落生成结构节点。

### Canvas Library

- 汇总所有结构图。
- 按书籍、主题、课程、语言、时间排序。
- 点击结构图进入 Writing Studio。

### Writing Studio

- 富文本编辑。
- 从结构图导入标题、问题、论点和材料。
- 主动出题：比较题、解释题、批判题、迁移题、外语表达题。
- AI 互动：追问、指出空白、建议补充阅读或语料。
- 文稿确认后进入发布与衍生生成。

### Language Tools

- 字典插件。
- 生词本。
- 文本转语音 TTS。
- 文稿转英文或西班牙语绘本。

### Publish And Share

- 发布用户作品。
- 分享结构图或文稿。
- 展示作品带来的认同反馈，强化创作动力。

## Non-Goals For MVP

- 不先做完整版权书库。
- 不先做复杂社交网络。
- 不先做全自动长篇写作代替用户。
- 不先做所有语言，先支持中文、英文、西班牙语。

## Success Metrics

- 用户是否能从一段阅读文本生成结构图。
- 用户是否能从结构图进入写作并完成一篇短文。
- 用户是否接受系统主动出题，而不是把它视为干扰。
- 用户是否愿意发布或分享最终作品。
- 用户是否能积累生词、语料和写作片段。

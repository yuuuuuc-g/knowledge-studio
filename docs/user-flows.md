# User Flows

## Flow 1: Read And Map

1. User opens a classic book from Bookshelf.
2. Reader shows the text on the left.
3. Canvas opens on the right.
4. User highlights a paragraph.
5. AI suggests structure nodes.
6. User accepts, edits or deletes nodes.
7. CanvasMap is saved to Canvas Library.

## Flow 2: Map To Writing

1. User opens Canvas Library.
2. User selects a structure map.
3. Writing Studio opens with imported nodes and relations.
4. Question Engine asks several prompts.
5. User answers one prompt.
6. AI follows up with missing evidence and a sharper question.
7. User expands the answer into a draft.

## Flow 3: Language Growth

1. User reads English source text.
2. User clicks unknown words.
3. Dictionary plugin shows definition, examples and pronunciation.
4. Word is added to vocabulary notebook.
5. Writing Studio asks the user to reuse selected words in a short paragraph.
6. TTS reads the paragraph aloud.

## Flow 4: Publish And Derive

1. User confirms the final draft.
2. System offers publish, share, translate, picture book and TTS options.
3. User generates an English picture book version.
4. User reviews and edits generated pages.
5. User publishes or shares the work.
6. Recognition feedback appears in the user profile and project history.
